# 📊 Sales Data Cleaning Project

## 🔹 Overview
This project focuses on cleaning and preparing a small sales dataset (50 rows) to improve data quality and make it ready for analysis.

---

## 📁 Dataset
- Format: CSV / Excel  
- Records: 50 rows  
- Columns: City, Sales, Date  

---

## 🧹 Data Cleaning Tasks
- Standardized city names (Cairo, Alexandria, Giza, etc.)  
- Removed duplicate records  
- Handled missing sales values  
- Converted date format to **YYYY-MM-DD**  
- Ensured overall data consistency  

---

## 🛠 Tools Used
- Microsoft Excel  
- Python (Pandas) *(optional)*  

---

## 🔄 Before vs After
| Issue | Solution |
|------|---------|
| Inconsistent city names | Standardized values |
| Missing sales values | Filled appropriately |
| Duplicate records | Removed |
| Mixed date formats | Converted to YYYY-MM-DD |

---

## 📤 Output
- Cleaned dataset (CSV / Excel)  
- Summary of changes  

---

## 📌 Key Results
- Improved data accuracy  
- Clean and structured dataset  
- Ready for analysis and reporting
